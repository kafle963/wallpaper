# Interactive Blob Wallpaper

An interactive, responsive 8-bit retro pixel text wallpaper featuring a smooth organic blob creature, customizable pixel fonts, physics-based interactions, and live color themes.

## Features
- **Interactive Blob Creature**: Responds to mouse tracking, dragging, flings, pets, and double-clicks.
- **Retro Pixel Fonts**: Customizable typography powered by Google Fonts (`Press Start 2P`, `Silkscreen`, `Pixelify Sans`, `VT323`, `Fraunces`).
- **Flexibility Panel**: Live settings menu (`⚙ FLEXIBILITY`) to switch fonts, color palettes, text scale, creature scale, and custom greetings.
- **Sound FX & CRT Filter**: Synthesized 8-bit sound effects via Web Audio API and optional retro scanlines overlay.
- **Responsive Layout**: Designed for desktop screens, mobile devices, and live wallpaper engines.

## Usage
Simply open `index.html` in any web browser, or load it into **Lively Wallpaper** / **Wallpaper Engine** to use it as your live Windows desktop background.
